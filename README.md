# Retro GFX - Electric 90s Wallpaper Website

A nostalgic, 90s-inspired wallpaper showcase website built with Vanilla JavaScript and Vite. This project captures the essence of the "Electric 90s" with a retro terminal interface, neon aesthetics, and classic Indian cinema references.

## 🌟 Features

-   **Retro Aesthetic**: Immersive 90s design featuring neon colors, scanlines, and retro fonts (Righteous, VT323, Space Mono).
-   **Interactive Terminal**: A typing animation welcome message that simulates a vintage command-line interface.
-   **Dynamic Animations**:
    -   Background "beams" animation for a cyberpunk/sci-fi feel.
    -   Interactive hover effects and smooth scrolling.
-   **Wallpaper Gallery**: A grid layout showcasing wallpapers with metadata (File ID, Date).
-   **Download & Preview**:
    -   Click to preview wallpapers in a modal.
    -   Direct download links for high-quality images.
-   **Request System**: A "Request Wallpaper" modal that allows users to send wallpaper requests via email.

## 🛠️ Tech Stack

-   **Build Tool**: [Vite](https://vitejs.dev/)
-   **Core**: HTML5, CSS3, Vanilla JavaScript (ES Module)
-   **Fonts**:
    -   *Righteous* (Headers/Logos)
    -   *VT323* (Body/Terminal text)
    -   *Space Mono* (Technical data)
-   **Styling**: Custom CSS with CSS variables for neon theming.

## 🎨 Design Notes

The design uses a high-contrast dark theme with:
-   **Neon Cyan** (`#0ff`) and **Neon Pink** (`#f0f`) accents.
-   CRT monitor effects like scanlines and text glow.
-   A mix of "glitch" and "cyberpunk" vibes tailored for a nostalgic Indian cinema context.
